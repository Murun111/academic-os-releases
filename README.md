# Academic OS releases

Installers for Academic OS, a local-first student dashboard. Website: https://academicos.net

## Download

Latest release: https://github.com/Murun111/academic-os-releases/releases/latest

- Mac: download `AcademicOS.dmg`, drag the app to Applications, then right-click it and choose Open the first time.
- Windows: download `AcademicOS-windows.zip`, extract it, and run `academic-os.exe` inside.
- Linux / Chromebook (Crostini): download `AcademicOS-linux.tar.gz`, extract it, and run `./academic-os/academic-os`.
